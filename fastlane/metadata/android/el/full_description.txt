Μια επανυλοποίηση ανοιχτού κώδικα του πιο διάσημου παιχνιδιού δημιουργίας πολιτισμών όλων των εποχών — γρήγορο, μικρό σε μέγεθος, χωρίς διαφημίσεις, δωρεάν για πάντα!

Χτίστε τον πολιτισμό σας, ερευνήστε τεχνολογίες, επεκτείνετε τις πόλεις σας και νικήστε τους εχθρούς σας!

Αιτήματα; Σφάλματα; Θέλετε να βοηθήσετε στην ανάπτυξη; Η λίστα εργασιών για την εφαρμογή βρίσκεται στη διεύθυνση https://github.com/yairm210/Unciv/issues

Ερωτήσεις; Σχόλια; Ελάτε μαζί μας στο Discord στη διεύθυνση https://discord.gg/bjrB4Xw ;)

Θέλετε να βοηθήσετε στη μετάφραση του παιχνιδιού στη γλώσσα σας; Δείτε το https://yairm210.github.io/Unciv/Translating/Translating/

Ο κόσμος σας περιμένει! Θα μετατρέψετε τον πολιτισμό σας σε μια αυτοκρατορία που θα αντέξει στη δοκιμασία του χρόνου;

Η άδεια «πλήρης πρόσβαση στο δίκτυο» απαιτείται για τις λήψεις που ξεκινά ο χρήστης και για τη λειτουργία πολλών παικτών. Όλες οι άλλες αναφερόμενες άδειες περιλαμβάνονται αυτόματα από το API που χρησιμοποιείται για την υλοποίηση των ειδοποιήσεων σειράς στην λειτουργία πολλών παικτών. Οι άδειες δικτύου χρησιμοποιούνται για την εμφάνιση λίστας τροποποιήσεων, την λήψη τροποποιήσεων, τη λήψη μουσικής και την αποστολή/λήψη παιχνιδιών πολλών παικτών. Καμία άλλη επικοινωνία μέσω διαδικτύου δεν ξεκινά από το Unciv.
